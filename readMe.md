# AuthController

## 1️⃣ 로그인 (Login)

| 항목               | 내용                                                                                           |
|--------------------|------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/login`                                                                                    |
| **Method**         | `POST`                                                                                          |
| **Request 파라미터** | `email` (String), `password` (String)                                                           |
| **Response**       | **성공**: `200 OK`, `userDto` (UserDto), 응답 헤더: `AccessToken: 새로운 액세스 토큰` <br> **실패**: `400 Bad Request`, `"등록되지 않은 ID"` 또는 `"비밀번호 불일치"` |
| **설명**            | 사용자가 로그인 시, **email**과 **password**로 인증을 시도합니다. 로그인 성공 시 **access token** 과 **UserDto**가 반환되며, **refresh token**은 쿠키에 저장됩니다. |

---

## 2️⃣ 회원가입 (Join)

| 항목               | 내용                                                                                                           |
|--------------------|--------------------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/join`                                                                                                 |
| **Method**         | `POST`                                                                                                       |
| **Request 파라미터** | `email` (String, 필수), `password` (String, 필수), `nickname` (String, 필수), `birth` (String, 필수), `preGenres` (List<String>, 필수) |
| **Response**       | **성공**: `200 OK`, `"회원가입 성공"` <br> **실패**: `400 Bad Request`, `"이미 존재하는 ID"`                                 |
| **설명**            | 새로운 사용자가 가입할 때 사용됩니다. 이미 등록된 이메일일 경우 `"이미 존재하는 ID"`라는 응답이 반환됩니다. 성공적으로 가입되면 `"회원가입 성공"` 메시지가 반환됩니다.          |

---

## 3️⃣ 로그아웃 (Logout)

| 항목               | 내용                                                                                           |
|--------------------|------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/logout`                                                                                 |
| **Method**         | `POST`                                                                                          |
| **Request 파라미터** | 없음 (단, 쿠키에서 `refresh` 토큰 필요)                                                        |
| **Response**       | **성공**: `200 OK`, `"로그아웃 성공"` <br> **실패**: `400 Bad Request`, `"옳바르지 않은 리프레시 토큰"` 또는 `"리프레시 토큰 없음"` |
| **설명**            | 사용자가 로그아웃할 때, **refresh token**을 삭제하고 쿠키에서 **refresh**를 만료시킵니다. `refresh` 토큰이 없을 경우 `"옳바르지 않은 리프레시 토큰"` 메시지가 반환됩니다. |

---

## 4️⃣ Access Token 재발급 (Reissue Access Token)

| 항목               | 내용                                                                                           |
|--------------------|------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/reissue`                                                                                 |
| **Method**         | `POST`                                                                                          |
| **Request 파라미터** | `email` (String)                                                                                |
| **Response**       | **성공**: `200 OK`, `"access token 재발급 성공"`, 응답 헤더: `AccessToken: 새로운 액세스 토큰` <br> **실패**: `400 Bad Request`, `"리프레시 토큰 없음"` 또는 `"리프레시 토큰 만료. 재로그인 필요"` |
| **설명**            | 사용자의 `refresh token`을 기반으로 새로운 **access token**을 발급합니다. `refresh token`이 만료되었거나 존재하지 않는 경우, `"리프레시 토큰 만료. 재로그인 필요"` 메시지가 반환됩니다. |

---

## 5️⃣ 사용자 정보 수정 (Update)

| 항목               | 내용                                                                                                       |
|--------------------|----------------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/update`                                                                                           |
| **Method**         | `POST`                                                                                                   |
| **Request 파라미터** | `token` (String, 헤더), `nickname` (String, 선택), `birth` (String, 선택), `preGenres` (List<String>, 필수)      |
| **Response**       | **성공**: `200 OK`, `"업데이트 성공"` <br> **실패**: `400 Bad Request`, `"옳바르지 않은 액세스 토큰"` 또는 `"사용자를 찾을 수 없습니다."`  |
| **설명**            | 사용자가 자신의 정보를 수정할 때 사용됩니다. 올바른 액세스 토큰을 제공해야 하며, **nickname**, **birth**, **preGenres**를 선택적으로 수정할 수 있습니다. |

---

## 6️⃣ 사용자 탈퇴 (Delete)

| 항목               | 내용                                                                                           |
|--------------------|------------------------------------------------------------------------------------------------|
| **URL**            | `/auth/delete`                                                                                 |
| **Method**         | `POST`                                                                                          |
| **Request 파라미터** | `token` (String, 헤더), `email` (String)                                                       |
| **Response**       | **성공**: `200 OK`, `"탈퇴 성공"` <br> **실패**: `400 Bad Request`, `"옳바르지 않은 액세스 토큰"` 또는 `"탈퇴는 본인 혹은 관리자만 가능"` |
| **설명**            | 사용자가 자신의 계정을 탈퇴할 때 사용됩니다. 본인 계정이나 관리자 권한을 가진 사람만 탈퇴할 수 있습니다. |

---

## 7️⃣ 멤버십 가입 (Membership)

| 항목               | 내용                                                                                     |
|--------------------|----------------------------------------------------------------------------------------|
| **URL**            | `/auth/membership`                                                                      |
| **Method**         | `POST`                                                                                  |
| **Request 파라미터** | `token` (String, 헤더)                                                                 |
| **Response**       | **성공**: `200 OK`, `"멤버쉽 가입 성공"` <br> **실패**: `400 Bad Request`, `"유효하지 않은 액세스 토큰"` 또는 `"존재하지 않는 유저"` |
| **설명**            | 사용자가 멤버십에 가입할 때 사용됩니다. 올바른 **액세스 토큰**을 제공해야 하며, 가입 성공 시 **회원 등급이 변경**됩니다. |
