# PostController

## 1️⃣ 게시글 작성 (Write)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/write`                                                                                   |
| **Method**         | `POST`                                                                                           |
| **Request 파라미터** | `title` (String, 필수), `content` (String, 필수), `kind` (String, 필수), `token` (String, 필수), `files` (List<MultipartFile>, 선택) |
| **Response**       | **성공**: `200 OK`, `"작성 완료"` <br> **실패**: `400 Bad Request`, `"잘못된 액세스 토큰"`        |
| **설명**            | 사용자가 게시글을 작성합니다. 제목, 내용, 종류, 토큰을 입력받고, 첨부파일이 있을 경우 파일도 업로드됩니다. |

---

## 2️⃣ 게시글 조회 (Get All)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/get/all`                                                                                 |
| **Method**         | `GET`                                                                                             |
| **Request 파라미터** | `size` (int, 필수), `page` (int, 필수)                                                           |
| **Response**       | **성공**: `200 OK`, `post` (List<PostDto>), `nickname` (List<String>), `total` (long) <br> **실패**: `400 Bad Request` |
| **설명**            | 게시글 목록을 페이징 처리하여 조회합니다. 페이지 크기(`size`)와 페이지 번호(`page`)를 파라미터로 받습니다. |

---

## 3️⃣ 게시글 조회 (Kind)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/get/kind`                                                                                 |
| **Method**         | `GET`                                                                                             |
| **Request 파라미터** | `size` (int, 필수), `page` (int, 필수), `kind` (String, 필수)                                    |
| **Response**       | **성공**: `200 OK`, `post` (List<PostDto>), `nickname` (List<String>), `total` (long) <br> **실패**: `400 Bad Request` |
| **설명**            | 특정 카테고리(`kind`)에 해당하는 게시글 목록을 조회합니다. 페이지 크기(`size`), 페이지 번호(`page`), 종류(`kind`)를 파라미터로 받습니다. |

---

## 4️⃣ 게시글 상세 조회 (Get Detail)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/{postId}`                                                                                 |
| **Method**         | `GET`                                                                                             |
| **Request 파라미터** | `postId` (long, 필수)                                                                            |
| **Response**       | **성공**: `200 OK`, `post` (PostDto), `postFile` (List<String>), `writer` (String), `commentList` (List<CmtDto>) <br> **실패**: `400 Bad Request`, `"게시글이 존재하지 않음"` |
| **설명**            | 게시글의 상세 정보를 조회합니다. 게시글의 파일과 댓글도 함께 반환됩니다. |

---

## 5️⃣ 게시글 수정 (Update)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/update`                                                                                   |
| **Method**         | `POST`                                                                                             |
| **Request 파라미터** | `postId` (long, 필수), `content` (String, 필수), `token` (String, 필수), `files` (List<MultipartFile>, 선택) |
| **Response**       | **성공**: `200 OK`, `"수정 완료"` <br> **실패**: `400 Bad Request`, `"존재하지 않는 게시글"` / `"유효하지 않은 토큰"` / `"작성자만 수정 가능"` |
| **설명**            | 게시글의 내용을 수정합니다. 파일을 첨부하여 수정할 수도 있으며, 게시글의 작성자만 수정할 수 있습니다. |

---

## 6️⃣ 게시글 검색 (Search)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/search`                                                                                   |
| **Method**         | `GET`                                                                                             |
| **Request 파라미터** | `category` (String, 필수), `keyword` (String, 필수), `size` (int, 필수), `page` (int, 필수)       |
| **Response**       | **성공**: `200 OK`, `post` (List<PostDto>), `nickname` (List<String>), `total` (long) <br> **실패**: `400 Bad Request` |
| **설명**            | 게시글을 제목, 내용, 작성자 등으로 검색합니다. `category`에 따라 검색 조건을 다르게 설정할 수 있습니다. |

---

## 7️⃣ 게시글 삭제 (Delete)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/post/delete/{postId}`                                                                          |
| **Method**         | `POST`                                                                                             |

| **Response**       | **성공**: `200 OK`, `"삭제 완료"` <br> **실패**: `400 Bad Request`, `"존재하지 않는 게시글"` / `"유효하지 않은 토큰"` / `"삭제는 관리자와 작성자만 가능"` |
| **설명**            | 게시글을 삭제합니다. 삭제는 관리자 또는 작성자만 할 수 있습니다. |

---

## 8️⃣ 게시글 좋아요 (Like)

# CommentController

## 1️⃣ 댓글 작성 (Write)

| 항목               | 내용                                                                                             |
|--------------------|--------------------------------------------------------------------------------------------------|
| **URL**            | `/comment/write`                                                                                 |
| **Method**         | `POST`                                                                                             |
| **Request 파라미터** | `token` (String, 필수), `postId` (long, 필수), `content` (String, 필수)                        |
| **Response**       | **성공**: `200 OK`, `"댓글 작성 성공"` <br> **실패**: `400 Bad Request`, `"존재하지 않는 게시글"` / `"유효하지 않은 토큰"` |
| **설명**            | 사용자가 댓글을 작성합니다. 게시글이 존재하는지 확인한 후, 유효한 토큰을 통해 작성자를 확인하고 댓글을 저장합니다. |

---

| **Request 파라미터** | `token` (String, 필수), `commentId` (long, 필수)                                                  |
| **Response**       | **성공**: `200 OK`, `"삭제 완료"` <br> **실패**: `400 Bad Request`, `"존재하지 않는 댓글"` / `"유효하지 않은 토큰"` / `"삭제는 관리자와 작성자만 가능"` |
| **설명**            | 댓글을 삭제합니다. 댓글이 존재하는지 확인한 후, 유효한 토큰을 통해 작성자 또는 관리자 권한을 확인하고 삭제합니다. |

---

# MusicController

| 항목               | 내용                                      |
|--------------------|-----------------------------------------|
| **URL**           | `/music/all`                            |
| **Method**        | `GET`                                   |
